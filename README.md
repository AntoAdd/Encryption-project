# Encryption-project

This is a project developed for the Operating System Course at UNICAM (Università degli Studi di Camerino).

## Project Overview
This project uses client-server architecture with socket programming to transfer encrypted files. 
The Caesar cipher is implemented for basic encryption.
The client's UI was designed with Glade and controlled with the GTK library.

## Key Features

* Client-server file transfer.
* Caesar cipher encryption.
* GUI using Glade and GTK.

## Usage

This program was tested and used with two virtual machines running on the same computer.

1.  Run the server on both virtual machines, using the CLI.
2.  Launch the client application via the graphical user interface (GUI), enter the hostname of receiver, then enter the file path and the shift value.
3.  Repeat step 2 on the other virtual machine.
4.  Transfer encrypted files between the two virtual machines.
